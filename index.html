rclone-edo

rclone-edo is a personal backup tool used only by its owner (Kuuga Noji). It copies the owner's own project files from his computer to his own Google Drive using rclone.

rclone-edo は、所有者（野地空我）本人だけが使う個人用のバックアップツールです。本人のパソコンにある制作ファイルを、rclone を使って本人の Google ドライブにコピーします。

Privacy Policy / プライバシーポリシー

  • The app requests only the drive.file scope, so it can access only files it created itself. / このアプリが求める権限は drive.file だけで、自分で作成したファイル以外にはアクセスしません。
  • Data is stored only in the owner's own Google Drive. It is not sent to, shared with, or sold to any third party. / データは本人の Google ドライブにだけ保存され、第三者への送信・共有・販売は行いません。
  • No analytics, advertising, or tracking is used. / 解析・広告・トラッキングは使いません。
  • Access can be revoked at any time from Google Account permissions. / アクセスは Google アカウントの設定からいつでも取り消せます。
